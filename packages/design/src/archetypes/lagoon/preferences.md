# Preferences

What people show they want as they work with Lagoon, newest first. Record each one when a person
corrects a screen, picks between versions, or accepts something a check flagged. A preference that
conflicts with the library keeps both entries, marked; the newer one, from the person closest to the
design, wins until someone settles it.

## Format

```
### <date> · <short name>
- **What changed:** <before → after>
- **Who:** <person or role>
- **Screen:** <recipe or screen id>
- **Reach:** this screen | this kind | everywhere (if unsure, the narrowest, and ask)
- **Conflicts with:** <library entry, or none>
```
