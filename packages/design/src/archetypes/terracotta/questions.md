# Questions

At most ten, about reasons and conflicts, ordered by how much the answer would change the library.

1. **Which panels lift, and why?** On the studied screens separated panels are mostly shadow-only (73%) or hairline-only (22%), and only the booking panel has both. Is "both" reserved for the commit panel on purpose, or is it a leftover of an older card style?
2. **Is the gradient for guests only?** The gradient action appears on guest screens (booking, log in, help, a landing page); host tools in the published screenshots use ink. Is that a rule, or did the host tools simply not get the gradient yet?
3. **Section headings at 500 or 600?** Large titles are 500 and some section headings are 600; on the studied place pages only about one heading in ten is set apart by weight. Which is newer, and which should a new screen follow?
4. **Grey or ink for the line under a title?** The landing page's line under its title is grey; the help home's panel sentence and the place description are ink. When is the sentence grey?
5. **Where do uppercase captions belong?** 3.5% of headings and button labels measured are uppercase. Is uppercase only for the booking fields' 10px captions, or also for small labels elsewhere?
6. **Mixed button corners:** 8px (help), 12px (most buttons), full pills (the booking action, chips, header icons). Is the pill booking action the newer style that others will follow?
7. **What does the logged-in desktop account page look like?** The settings layout here is inferred from public patterns; a screenshot would confirm or correct it.
8. **Is the empty state a block in the column or a centred page?** The no-results search state was not measured (the page never settles), so the empty-state recipe is inferred.
9. **What is the host dashboard on a desktop?** The published host screens are the phone app; is the desktop arrangement (floating reservation cards, outline panels, listings as photo cards) the right translation?
10. **Dark mode:** the dark palette is published but the website renders light. Should Terracotta lead with light only, and treat dark as the phone app's?
