# Edit a setting

**The job:** show a value someone set and let them change it.

## What Summit does

1. **Rows, not controls:** a 12px grey label over the value in 14px at 600, a ghost pencil button at the right, a hairline under each row.
2. **Rows grouped in white cards** under a 20px title at 600 and one 14px grey line about what the group does.
3. **A select inline** only for a value with a few fixed options (main sport).
4. **Deleting the account last**, in its own card: a 16px title, one line about what is lost, a white "Download data" and the red "Delete account".

## Where it appears

- `settings`.
- Source: `observed` in a published screenshot of the web settings page (label over value with a pencil, the current section filled orange, an orange upgrade button in the account column, an orange trial button in the bar).

## Variations and triggers

- **Editing a row** opens it in place or in a dialog with Save (orange) and Cancel (white).
- **Many sections:** the side column (current item filled orange) lists them; each opens its own page.

## What it does not do

- No switches and no radio lists on the page; a row shows the value in words ("Hidden, 200 m from each end").
- No more than one orange button in the main column; Upgrade sits in the account card.
- No autosave without saying so.

## Why

- `inferred`: settings are read far more often than changed; rows read like a summary and keep the page calm.
