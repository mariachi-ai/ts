# Questions

At most ten, about reasons and conflicts, ordered by how much the answer would change the library.

1. **What does the signed-in web app look like today?** The app recipes follow older published screenshots of the web dashboard, session and settings pages and the current public pages' type. Recent desktop screenshots would confirm or correct the bar, the side columns and the widths.
2. **Is the app bar's "Start free trial" right for every screen?** A published settings screenshot shows it; it is not known whether members on a plan see something else there (the language shows it on every app recipe).
3. **600 or 700 for titles?** The current public pages set titles and buttons at 600; the older app-shell page (challenges) uses 700 on its buttons and card title. The language keeps 600 only. Is 700 the older habit?
4. **How big are marketing headlines?** Over photographs the public pages run 48–64px; the measured ratio elsewhere is about 2×. The language keeps 32px everywhere. Should a page that sells over a picture go bigger?
5. **Links: orange or blue?** Help pages and the not-found page use blue links; the public bar and sign-in use orange. The language keeps orange for every link and blue for focus only.
6. **Switches anywhere?** No switch was seen in the web settings; the phone app may use them. Should the web never show one?
7. **Rows or cards for long lists?** Public lists separate items by space (90% of collections); the app screenshots use cards and hairline tables. Which is the rule for a new list?
8. **The plans page's ground.** It opens on a dark band with a red-orange glow; every other page is white or off-white. Is the dark band only for selling?
9. **Feed avatars.** Real avatars are photos; the language uses initials on grey. Is a plain grey disc closer to the intent than initials?
10. **Dark mode for the web.** The web has no dark mode in what was seen; the language's dark values come from the phone app. Should a web build offer it?
